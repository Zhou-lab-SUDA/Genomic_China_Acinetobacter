# Rebuttal Figure 6

SNP-distance sensitivity analyses for temporal calibration and geographic
dissemination. The packaged tables include pair-level SNP/TreeTime comparisons,
calibration summaries, binned geographic-distance results and annual km/SNP
summaries/comparisons.

The three scripts are upstream analytical provenance. They depend on the full
hybrid SNP matrix, sample index, TreeTime nexus, sampling dates, city-distance
matrix and metadata workbook in the project-level analysis directories. These
large/interdependent sources are listed in `DATA_PROVENANCE.tsv`; the direct
figure tables are frozen in `data/`.
