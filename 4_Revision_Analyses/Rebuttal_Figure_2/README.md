# Rebuttal Figure 2

This directory contains the root-to-tip date-randomisation analysis. Ten date
permutations were evaluated, each with ten internal 50% subsamples.

Run `python code/date_randomisation_rttd.py` to regenerate the result tables and
the four-panel SVG under `reproduced_date_randomisation/`.

The survival panel and associated data are not included in this repository
snapshot. Documentation of the fixed analysis-cohort definition is pending;
see `../PLACEHOLDERS.md`.
