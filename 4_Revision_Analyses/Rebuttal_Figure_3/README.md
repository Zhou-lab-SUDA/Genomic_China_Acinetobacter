# Rebuttal Figure 3

Adhesion of six isolates to A549 cells at MOI 10 and 20. The source workbook is
`data/source_adhesion_measurements.xlsx`. The tidy TSV contains one row per
independent experiment and is the direct input to the packaged plotting script.

Run `python code/plot_selected_moi_logcfu.py`. Bars are strain means, error bars
are sample standard deviations and points are the three independent experiments.
