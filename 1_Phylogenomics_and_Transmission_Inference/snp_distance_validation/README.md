# SNP-distance validation

These analyses compare divergence time with pairwise SNP distance calculated
from the recombination-masked alignment. The tables include pair-level
comparisons, year calibration, geographic-distance bins and annual km-per-SNP
summaries.

Calendar time remains the unit used for dissemination velocity because it
supports direct comparison between epidemiological periods. The SNP-based
analysis tests whether the principal spatial relationships depend on molecular
dating.

The upstream scripts require the full SNP matrix, sample index, dated tree,
sampling dates, city-distance matrix and genome metadata. Figure-level derived
tables are included under `data/`.
