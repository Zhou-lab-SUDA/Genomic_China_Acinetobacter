# Temporal-signal sampling sensitivity

Five sampling schemes were evaluated: 50% random downsampling, sampling
weighted by city population, year-balanced sampling, city-balanced sampling,
and combined city/year-balanced sampling. Each scheme contains ten independent
replicates. The replicate and summary tables retain results for the combined
dataset and each major ESL lineage.

Early isolates are sparse. Year balancing therefore changes the weight of
early observations, particularly for the combined dataset and ESL2.4. ESL2.5
retains a positive temporal signal across all five schemes.
