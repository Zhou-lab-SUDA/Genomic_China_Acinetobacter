# Evolutionary signatures and phenotype data

This directory contains city-level association analyses, genomic variation and
phenotype measurements used to compare ESL2.4 and ESL2.5.

The analyses support associations between lineage, genomic features and
measured phenotypes. They do not establish that capsule type or the identified
gene disruptions cause the adhesion, colonisation or virulence phenotypes.

## Contents

- `phenotype_experiments/`: antimicrobial susceptibility, capsular
  polysaccharide, gene-expression, A549 adhesion, nasal-colonisation and
  systemic-infection experiments.
- `snp_density/`: annotated lineage-associated SNP-density peaks.
- `city_associations/`: univariate city associations and multiple-testing
  adjustment.
- `Degree.py`: association between city connectivity and lineage prevalence.
